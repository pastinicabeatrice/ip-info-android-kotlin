# IP Info (Kotlin)

Aplicație Android în Kotlin, cu Jetpack Compose, pentru informații despre adrese IP și țări.

## Funcționalități

- introducerea unei adrese IP și istoricul căutărilor
- informații despre IP și țara asociată, obținute de la [ipapi.co](https://ipapi.co)
- operații asincrone cu corutine
- procesarea datelor JSON
- preferințe: temă întunecată, limbă, dimensiunea textului, stil vizual

## Tehnologii

Kotlin, Jetpack Compose, Material 3, corutine, OkHttp, Retrofit, kotlinx.serialization, DataStore

## Cerințe

Android Studio, Android SDK 34, dispozitiv sau emulator cu Android 7.0 (API 24) sau mai nou.

## Rulare

Se deschide folderul în Android Studio, se așteaptă sincronizarea Gradle și se rulează configurația `app`.
